You can request several actions for one unit in the same tick, but usually only one will work because its first successful action starts its cooldown.

Actions happen in this order:

1. gem transfers;
2. attacks;
3. moves; and
4. unit creation.

Actions of the same type happen in random order. For example, every attack happens before any move, but the order of two attacks is random.

If you ask one unit to move to two positions in the same tick, either move may happen first. The other move then fails because the unit is on cooldown.

The same rule applies when two opposing units try to move into the same empty position. Either move may happen first; it is not guaranteed to be a 50-50 outcome.
